# 🧭 Polaris — Baguio Jeepney Route Navigator
![status](https://img.shields.io/badge/status-Prototype-yellow)

**Polaris** is a lightweight jeepney route navigation prototype designed for commuters in **Baguio City, Philippines**.

It helps users determine which jeepney route to take based on their current location and intended destination, reducing the need to ask for directions or rely on more expensive transportation options.

---

## ✨ Features

- 🗺️ Interactive map of Baguio City
- 📍 Manual and GPS-based location selection
- 🔎 Destination search
- 🚐 Destination-based jeepney route recommendations
- 🛣️ Jeepney route visualization
- 📌 Boarding and drop-off point indicators
- 🚶 Walking distance information
- ⏱️ Estimated travel time
- 🔐 Location permission and consent system
- 📱 Lightweight, mobile-oriented interface

---

## 🧭 How It Works

1. Open **Polaris** and view the interactive map.
2. Enable GPS and allow location access, or manually select your current location.
3. Select your intended destination.
4. Polaris displays available jeepney routes that can take you toward the destination.
5. Select a recommended route to view its path, boarding point, drop-off point, estimated travel time, and walking information.

---

## 📍 Prototype Coverage

The current prototype is centered around the **University of the Cordilleras** and includes selected destinations around Baguio City:

- Saint Louis University
- 7-Eleven Rimando Street
- Rose Garden, Burnham Park
- Baguio Cathedral

Route and travel information in the prototype is limited and is intended primarily for demonstrating the proposed system.

## 🎯 Project Purpose

Polaris was developed as a high-fidelity prototype for an academic project exploring a lightweight and accessible navigation system specifically for Baguio City's jeepney transportation network.

The prototype demonstrates how commuters, students, and tourists could identify suitable jeepney routes without needing prior knowledge of Baguio City's public transportation system.

---

## ⚠️ Disclaimer

**Polaris is currently a prototype and should not be used for actual navigation.**

Jeepney routes, estimated travel times, boarding points, drop-off points, and other transportation information presented by the prototype may be incomplete or inaccurate.

Map data is provided by **OpenStreetMap contributors**.
